## Core Features:

- Secure Access: Secure Google login with email validation (omar.sanchezfigueroa@mercadolibre.com.mx will be authorized).
- Looker Studio Integration: Main dashboard displaying the Looker Studio report: https://lookerstudio.google.com/reporting/2a1228bc-36fb-4f28-8190-38a5149ee670/page/p_t5v3dj3pnd.
- Dynamic Navigation: Navigation menu with icons for Home, Control de Pérdidas, CCM, Security, Manager, and BOT.
- Loss Prevention Page: Dedicated page for 'Control de Pérdidas' (Loss Prevention) - initial state: blank.
- CCM Page: Dedicated page for 'CCM' - initial state: blank.
- Security Page: Dedicated page for 'Security' - initial state: blank.
- Manager Page: Dedicated page for 'Manager' - initial state: blank.
- BOT Page: Dedicated page for 'BOT' - initial state: blank.

## Style Guidelines:

- Primary color: Mercado Libre Yellow (#FFD200) to align with brand recognition.
- Background color: Light yellow (#FAF5E6), a very light tint of the primary to avoid eye strain.
- Accent color: Blue (#29ABE2) to provide contrast and highlight interactive elements; analogous to yellow, suggesting communication, and high-tech contexts such as visualization and data analysis.
- Body and headline font: 'Inter' sans-serif font, for a clean, neutral, and modern data-centric look.
- Use Mercado Libre-style icons for navigation and key features.
- Header area displaying the Mercado Libre logo.
- Clean and structured layout with a focus on data presentation and easy navigation.
- Subtle transitions and animations on navigation and data updates.
